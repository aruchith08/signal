# SIGNAL 📡 — Web Application (Frontend)

Next.js (App Router), TypeScript, and Tailwind CSS dashboard for browsing opportunities, managing notifications, and personalizing track preferences.

## Planned Features (Phase 1 & Phase 2)
* Opportunity Feed with category tabs (Competitive Programming, Hackathons, Internships, etc.)
* Deadline countdown timers and calendar integration
* Student profile onboarding (degree, branch, year, skills, interest tags)
* Telegram alert linking and preferences
